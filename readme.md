# Devoir n°1
_________________

* Vous allez finir la configuration de Git et Github (Pour ceux qui ne l'ont pas encore fait)
* Vous allez accepter ma demande de rejoindre le repository Github où je vais vous inviter

* Vous allez cloner la branche sur laquelle se trouve le Devoir n°1

* Faire le Devoir n°1

*  Vous allez créer votre propre branche où vous allez mettre votre code afin que je le vois

* Votre branche doit se nommer de la manière suivant

devoir_01_<prenom>

Par exemple: devoir_01_alassane


## En quoi consiste Le Devoir ?
_________________________________

* Rendez beau visuellement le tableau

* Alternez les couleurs des lignes (blanc/gris)

* Ajoutez une bordure spéciale à la dernière ligne

### Consigne
________________________

* N'utilisez pas les class, ni les id
* N'utilisez que les pseudo classes
* Rendez le travail visuellement bonus
